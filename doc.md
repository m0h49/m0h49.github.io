## 🧠 Архитектура приложения (`src/app.js`)

### Инициализация
- `init(container)` — экспортируемая функция, рендерит терминал в переданный DOM-элемент
- На старте применяется тема (по умолчанию: GruvboxDark)
- Если история пуста — автоматически запускается команда `banner`

### Состояние
- **История команд** — хранится в `localStorage('history')`, синхронизируется с `currentHistory`
- **Тема** — хранится в `localStorage('colorscheme')`, синхронизируется с `currentTheme`
- **Todo-лист** — хранится в `localStorage('terminal-todos')`, структура: `{ todos: [], nextId: 1 }`

### Управление историей
- `saveHistory(h)`, `loadHistory()` — чтение/запись `localStorage`
- `renderHistory(historyEl)` — отрисовка всех записей истории
- `renderCommands(historyEl)` — обёртка над `renderHistory` со скроллом ввода

### Обработка ввода (`handleKeyDown`)
| Клавиша       | Действие                             |
|---------------|--------------------------------------|
| `Enter`       | Выполнение команды, сохранение в историю |
| `ArrowUp`     | История: предыдущая команда           |
| `ArrowDown`   | История: следующая команда            |
| `Tab`         | Автодополнение по имени команды       |
| `Ctrl+L`      | Очистка истории (как `clear`)        |

### Рендеринг
- prompt: `guest@<hostname>:~$`
- Цвета подставляются из активной темы
- Mobile: prompt сворачивается до `❯`

## 🧮 Калькулятор (`calc`)

Собственный парсер, реализованный классами `Parser` и `CalcError`.

Грамматика (рекурсивный спуск):
```
Expression → Term (('+' | '-') Term)*
Term       → Factor (('*' | '/' | '%') Factor)*
Factor     → ('-' | '+')? Primary
Primary    → '(' Expression ')' | Number
Number     → [0-9]+ ('.' [0-9]+)?
```

Особенности:
- Операторы `**` и `^` — **не поддерживаются**, выбрасывают ошибку
- Деление/остаток на ноль → `CalcError`
- Поддержка унарных `+` и `-`
- Скобки любой вложенности

## 🔄 Конвертер единиц (`convert`)

Формат: `convert <value> <from> to <to>`

### Длина (Linear)
| Единицы                                        |
|------------------------------------------------|
| `m`, `km`, `cm`, `mm`, `mi`, `ft`, `in`, `yd` |

### Масса (Linear)
| Единицы                        |
|--------------------------------|
| `g`, `kg`, `mg`, `lb`, `oz`, `t` |

### Температура (Formula-based)
| Единицы        |
|----------------|
| `C`, `F`, `K`  |

### Данные (Linear)
| Единицы                                     |
|---------------------------------------------|
| `B`, `KB`, `MB`, `GB`, `TB` (десятичные)    |
| `KiB`, `MiB`, `GiB`, `TiB` (двоичные)       |

Функция `convertUnit()` определяет категории, конвертирует линейные через фактор, температурные — через Кельвин.
