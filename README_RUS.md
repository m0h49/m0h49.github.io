# m0h49 Terminal

Веб-сайт-портфолио с встроенным браузерным терминалом. Студент Школы 21, пишу на C, GDScript и Python.

## Архитектура (`src/app.js`)

### Инициализация
- `init(container)` — экспортируемая функция, рендерит терминал в переданный DOM-элемент
- На старте применяется тема (по умолчанию: GruvboxDark)
- Если история пуста — автоматически запускается `banner`

### Состояние (localStorage)
| Ключ             | Формат                    | Назначение                |
|------------------|---------------------------|---------------------------|
| `history`        | `[{command, outputs}]`    | История выполненных команд |
| `colorscheme`    | `{name, background, ...}` | Активная цветовая схема   |
| `terminal-todos` | `{todos, nextId}`         | Список задач              |

### Обработка ввода (`handleKeyDown`)
| Клавиша     | Действие                             |
|-------------|--------------------------------------|
| `Enter`     | Выполнение команды, сохранение в историю |
| `ArrowUp`   | История: предыдущая команда           |
| `ArrowDown` | История: следующая команда            |
| `Tab`       | Автодополнение по имени команды       |
| `Ctrl+L`    | Очистка истории (как `clear`)        |

### Рендеринг
- prompt: `guest@<hostname>:~$`
- Цвета подставляются из активной темы
- Mobile: prompt сворачивается до `❯`

## Калькулятор (`calc`)

Собственный парсер рекурсивного спуска (`Parser`, `CalcError`).

```
Expression → Term (('+' | '-') Term)*
Term       → Factor (('*' | '/' | '%') Factor)*
Factor     → ('-' | '+')? Primary
Primary    → '(' Expression ')' | Number
Number     → [0-9]+ ('.' [0-9]+)?
```

- `**` и `^` — не поддерживаются, ошибка
- Деление/остаток на ноль → `CalcError`
- Унарные `+` и `-`
- Скобки любой вложенности

## Конвертер единиц (`convert`)

Формат: `convert <value> <from> to <to>`

| Категория    | Единицы                                                    |
|-------------|------------------------------------------------------------|
| Длина       | `m`, `km`, `cm`, `mm`, `mi`, `ft`, `in`, `yd`             |
| Масса       | `g`, `kg`, `mg`, `lb`, `oz`, `t`                           |
| Температура | `C`, `F`, `K`                                              |
| Данные      | `B`, `KB`, `MB`, `GB`, `TB`, `KiB`, `MiB`, `GiB`, `TiB`   |

Линейные конвертируются через фактор, температурные — через Кельвин.
